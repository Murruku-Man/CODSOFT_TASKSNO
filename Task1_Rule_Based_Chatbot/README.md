# CODSOFT Task 1 - Rule-Based Chatbot

## Project Description

This project is a simple rule-based chatbot developed for Task 1 of the CodSoft Artificial Intelligence Internship.

The chatbot identifies user input using predefined rules and responds using `if-elif-else` statements and simple pattern matching.

## Features

- Responds to greetings
- Introduces itself
- Explains its capabilities
- Responds to "How are you?"
- Displays the current date
- Displays the current time
- Responds to thanks
- Handles goodbye commands
- Provides a default response for unknown inputs
- Runs directly in the Python terminal

## Technologies Used

- Python
- Conditional statements (`if-elif-else`)
- String pattern matching
- `datetime` module

## How to Run

1. Make sure Python is installed.
2. Open a terminal in this folder.
3. Run:

```bash
python chatbot.py
```

If your system uses `python3`, run:

```bash
python3 chatbot.py
```

## Example Conversation

```text
RULE-BASED CHATBOT
CODSOFT - TASK 1

Chatbot: Hello! I'm RuleBot.
Chatbot: Type 'bye' or 'exit' to end the conversation.

You: hi
Chatbot: Hello! Nice to meet you. How can I help you?

You: what is your name
Chatbot: I'm RuleBot, a simple rule-based chatbot created for the CodSoft AI internship.

You: what can you do
Chatbot: I can respond to greetings, answer basic questions, tell you the date and time, and handle simple conversations using predefined rules.

You: bye
Chatbot: Goodbye! Have a great day.
```

## Learning Outcome

This project demonstrates basic natural language processing concepts through keyword/pattern matching and shows how predefined rules can control a conversational flow.

## Internship Task

**Task 1: Chatbot with Rule-Based Responses**

The CodSoft task asks for a simple chatbot that responds to user inputs based on predefined rules using if-else statements or pattern matching techniques.
